# Netscout

**Netscout** is a comprehensive IT product finder and comparison tool designed to simplify the selection of network equipment. Built with modern web technologies, it offers a seamless experience for browsing, filtering, and comparing switches, routers, and other network devices.

![Project Banner](/placeholder.svg?height=400&width=800)

## 🚀 Features

- ** extensive Product Catalog**: Browse a wide range of network equipment including switches, routers, firewalls, and more.
- **Advanced Filtering**: Filter products by category, subcategory, series, port count, PoE support, and more.
- **Dynamic Comparison**: Compare multiple products side-by-side to make informed decisions.
- **Detailed Specifications**: View comprehensive technical specifications for each product.
- **Responsive Design**: Optimized for all devices, from desktops to mobile phones.
- **Modern UI**: Clean and intuitive interface built with shadcn/ui and Tailwind CSS.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🏁 Getting Started

Follow these steps to get the project running locally on your machine.

### Prerequisites

- Node.js (v18 or later)
- npm, yarn, or pnpm

### Installation

1.  **Clone the repository**

    ```bash
    git clone https://github.com/RoberaET/Netscout.git
    cd Netscout
    ```

2.  **Install dependencies**

    ```bash
    npm install
    # or
    yarn install
    # or
    pnpm install
    ```

3.  **Run the development server**

    ```bash
    npm run dev
    # or
    yarn dev
    # or
    pnpm dev
    ```

4.  **Open your browser**
    Navigate to [http://localhost:3000](http://localhost:3000) to see the application.
